# Relm

> Relm is an API-first CRM built for LLMs and AI agents. Contacts, companies, deals and activities are exposed over a REST API and a native Model Context Protocol (MCP) server, so an AI agent with a bearer key can read and write the CRM directly. The web dashboard is a thin human view. Free tier: 1,000 API requests/month, no credit card.

## Connect

- [REST API](https://api.relmcrm.com/v1): Base URL for all REST endpoints. Auth: `Authorization: Bearer relm_live_...`
- [MCP server](https://api.relmcrm.com/mcp): Native Model Context Protocol server (Streamable HTTP). Every CRM operation is a typed tool (41 of them). Start with `relm_describe_schema`.
- OAuth 2.1: authorization code + PKCE (S256) + refresh, with dynamic client registration at `https://api.relmcrm.com/oauth/register`. Discovery: `/.well-known/oauth-authorization-server` and `/.well-known/oauth-protected-resource`. Scope `crm`. An unauthenticated `tools/call` returns 401 + `WWW-Authenticate`. API keys remain supported.
- [A2A endpoint](https://api.relmcrm.com/a2a): Agent2Agent JSON-RPC (`message/send`); agent card at [/.well-known/agent-card.json](https://relmcrm.com/.well-known/agent-card.json).
- [OpenAPI spec](https://relmcrm.com/openapi.json): Machine-readable REST contract (OpenAPI 3.1) for the whole `/v1` surface.
- [Dashboard / sign up](https://app.relmcrm.com/): Mint API keys (live + free test mode), view records, manage billing.

## Objects

- Contacts (`/v1/contacts`, id `con_`): people; email-optional (phone or LinkedIn-only allowed); email is unique per workspace (a duplicate returns the existing record).
- Companies (`/v1/companies`, id `cmp_`): accounts; contacts and deals link to them.
- Deals (`/v1/deals`, id `deal_`): opportunities in a pipeline + stage.
- Activities (`/v1/activities`, id `act_`): notes/calls/emails/meetings; backdatable via `occurred_at`.
- Pipelines (`/v1/pipelines`): named pipelines with ordered stages.
- Automations (`/v1/automations`): single-step event-triggered "when X then Y" rules.
- Sequences (`/v1/sequences`): multi-step drip sequences with auto-enroll and exit conditions.
- Templates (`/v1/templates`): reusable email templates referenced by automations and sequences.
- Webhooks (`/v1/webhooks`): subscribe an https endpoint to events; HMAC-signed (`Relm-Signature: t=,v1=`), retried with backoff, dead-lettered after 6 attempts. Secret returned once on create.
- Custom fields (`POST /v1/fields`): register once, then send values under `custom_fields` on any object.
- Search (`/v1/search`): cross-object search; contact, company and deal lists also take a `?q=` substring filter (other lists use their exact filters - an unknown filter is rejected with 400 + valid_options).
- Schema (`/v1/schema`): live self-describing registry of objects, fields, enum values.
- Batch (`/v1/batch`, MCP `relm_batch`): up to 100 operations in one round-trip; metered per operation.

## Migrate

- [Migrate from HubSpot](https://relmcrm.com/learn/migrate-from-hubspot): export, map lifecycle stages to a pipeline and properties to custom fields; the agent runs the import.
- [Migrate from Pipedrive](https://relmcrm.com/learn/migrate-from-pipedrive): pipelines and stages map 1:1; activities and custom fields carry over.
- [Migrate from Salesforce](https://relmcrm.com/learn/migrate-from-salesforce): Leads and Opportunities become contacts and deals; picklists become validated enums.
- [Migrate from Attio](https://relmcrm.com/learn/migrate-from-attio): export per object; attributes map to Relm objects and custom fields.
- [Migrate from Airtable or Google Sheets](https://relmcrm.com/learn/migrate-from-airtable): tables become objects; views become automations and agent queries.
- [Migrate from GoHighLevel](https://relmcrm.com/learn/migrate-from-gohighlevel): sub-accounts map to workspaces, opportunities to deals; keep GHL for funnels.

## Key facts

- Errors are RFC-9457 problem+JSON with `valid_options` and `suggestion` so agents self-correct.
- Pricing: Free 1,000 req/mo; Pro $29/mo = 100,000 req/mo; Scale $249/mo = 2,000,000 req/mo. Overage $0.0001/request on paid plans, with an optional hard spend cap.
- Test mode is free and isolated from live data and billing. It is a sandbox, not storage - test records (contacts, companies, deals, activities) are auto-deleted 7 days after creation.
